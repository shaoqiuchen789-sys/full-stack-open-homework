# 0.6: New note in Single Page App diagram

```mermaid
sequenceDiagram
    participant user
    participant browser
    participant server

    user->>browser: Types a new note and clicks Save
    Note right of browser: spa.js handles the form submission

    Note right of browser: JavaScript prevents the normal form submission
    Note right of browser: The new note is added to the page immediately

    browser->>server: POST /exampleapp/new_note_spa<br/>Content-Type: application/json<br/>{"content":"New note","date":"timestamp"}
    activate server
    server-->>browser: 201 Created
    deactivate server

    Note right of browser: No redirect and no page reload occur
```
